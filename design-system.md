# KrishiVeda UI Design System

Based on designer-skills research, this document defines the comprehensive design system for the KrishiVeda UI remake, incorporating the "best of all" styles: Modern AgriTech + Clean Government + Friendly Farmer + Dashboard Pro.

## 1. Design Principles
- **Modern AgriTech**: Clean, data-rich interfaces with clear hierarchy
- **Clean Government**: Professional, trustworthy, accessible design
- **Friendly Farmer**: Approachable, warm, and human-centered
- **Dashboard Pro**: Data visualization excellence with clear metrics

### 3.2 Weight Scale
- Regular (400)

## 4. Spacing System

### 4.1 Base Unit
- 4px (base unit)

### 4.2 Spacing Scale
| Step | Value (px) |
|------|------------|
| 2xs | 2 |
| xs | 4 |
| sm | 8 |
| md | 16 |
| lg | 24 |
| xl | 32 |
| 2xl | 48 |
| 3xl | 64 |

### 4.3 Spacing Types
- **Inset**: Padding inside containers
- **Stack**: Vertical space between stacked elements
- **Inline**: Horizontal space between inline elements
- **Grid gap**: Space between grid/flex items

### 4.4 Density Modes
- **Compact**: Reduce spacing by one step
- **Comfortable**: Default spacing
- **Spacious**: Increase spacing by one step

## 5. Layout Grid

### 5.1 Breakpoints
- **Small**: 375-639px (phones)
- **Medium**: 640-1023px (tablets)
- **Large**: 1024-1439px (laptops)
- **Extra large**: 1440px+ (desktops)

### 5.2 Column Structure
- **Mobile**: 4 columns
- **Tablet**: 8 columns
- **Desktop**: 12 columns

### 5.3 Gutter
- 16px (all breakpoints)

### 5.4 Margins
- **Page margins**: 16px (mobile), 24-48px (desktop)
